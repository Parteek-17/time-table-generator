## Current milestone

## Done

- M1 (date sheet): `exams.prisma` (exams, sessions, papers, seat needs, seating plans, seats,
  duties), RLS SQL applied locally, `/exams` date-sheet API with plain-language clash check,
  e2e test `apps/api/src/exams/date-sheet.e2e.test.ts`, ADR 0080.
- M2: `POST /v1/seating/solve` (greedy, no CP-SAT) with one pytest file per rule
  (`services/solver/tests/seating`); BullMQ job `p6.seating` that builds the request from the
  date sheet and rooms and stores seats (`POST /exams/sessions/:id/seating`, `GET
/exams/seating/:planId`), e2e test with a fake solver.

- M3: invigilation in the solver (balanced matching, availability, never their own paper;
  `test_invigilation.py`), per-session unavailability (`GET …/invigilators`, `PUT
…/unavailable`), duties stored with the plan; e2e `invigilation.e2e.test.ts`.

- M4a: printouts as tables in `packages/shared/src/exams/outputs.ts` (hall chart, where-to-sit
  notice list, attendance sheets, duty chart); `GET /exams/seating/:planId/export?doc=&format=`
  (PDF via puppeteer-core like P2T, Excel via ExcelJS); `POST /exams/seating/:planId/publish`
  (archives the earlier plan, re-publishing an archived plan is the undo, emits
  `exam.seating.published`); `GET /exams/me` (student seats by sign-in email, teacher duties by
  linked login, published only, today onward). e2e `export/outputs.e2e.test.ts`.
