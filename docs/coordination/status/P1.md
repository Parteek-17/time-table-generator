  at startup once a worker is created there (`SampleDataListener`). Same version as P2T's.
- `apps/web` (dev): `@playwright/test` 1.64.1. Runs with the installed Microsoft Edge
  (`channel: 'msedge'`), so no browser download. Config in `apps/web/e2e/p1/` (no
  `package.json` script, since scripts are not P1's to add):
  `E2E_BASE_URL=http://demo.localhost:3001 pnpm --filter @slotwise/web exec playwright test -c e2e/p1`
  with the dev servers running. Not in CI yet.
