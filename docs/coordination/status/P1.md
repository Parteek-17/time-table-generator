Branch `p1/setup-snapshot` on `main` 271f570. No schema change (all tables came with 1a).

- **Teaching grid** `GET /teaching?termId=`, `GET /teaching/:cohortId`,
  `PUT /teaching/:cohortId/cells`, `PUT /teaching/:cohortId/mentors`. Rows = scheduled course
  parts (L/T/P) of the cohort's scheme; cells = sections, sub-groups or elective sections that
  need a teacher (`requiredTargets`). Each teacher carries assigned/max periods a week across
  all departments. Writes check `teaching.manage` with the cohort's department and the
  teachers' home departments, both for the teachers taken off and put on (service hods,
  ADR 0008). Clearing a cell archives the assignment. Lateral-entry cohorts point to the host.
- **Subject mentors** per course × cohort; one row per (term, course, cohort), archived/restored.
- **Fixed slots** CRUD `/fixed-slots` (`fixed_slot.manage`), with teachers; day and periods
  checked against the default bell schedule.
- **Timetable scopes** CRUD `/timetable-scopes` (`timetable_scope.manage`); running cohorts of
  the same term only; owned by the department when all cohorts are in one.
- **Readiness** `GET /terms/:id/readiness[?scopeId=]` → `readiness()` + term + scope.
- **`term.activated`**: `POST /terms/:id/activate` closes the active term and activates this
  one, emitting `{ termId, previousTermId }`; saving a term as active through `PUT/POST /terms`
  also emits it (previousTermId null). Emitted after commit via the new deferred
  `ctx.emit` of `MasterDataService.run`.
- **Screens**: `/teaching`, `/teaching/[cohortId]` (picker per cell with load badge "12/14" +
  words, co-teachers, subject mentors, Undo after every save), `/teaching/fixed-slots`,
  `/teaching/scope`, `/readiness` (7 groups, every problem with a fix button to its screen,
  teacher load, teaching days, per scope). Terms list: "Make current". Nav group "Who teaches
  what". Wizard step 11 = grid overview, step 12 = readiness + links; all 12 steps count
  towards "Setup N% done"; "Needs attention" shows the readiness error count.
