# P1 status

Plan: `docs/phase1/plan.md` (§7 milestones).

## Current milestone

1d — Excel/CSV import with templates: done (2026-10-27), not merged. ADR 0011.

- Templates (`.xlsx` with a "How to fill" sheet) for all 9 kinds: departments, programmes and
  branches, courses, rooms, faculty, batches and sections, students, holidays, teaching
  assignments. `GET /imports/templates/:kind`, downloaded at `/imports/templates/[kind]`.
- Upload (`POST /imports`, raw file body, up to 5 MB / 20,000 rows) → header row and columns
  matched automatically (the college's own names work) → every row checked → preview with
  plain-language problems per column → fix inline or skip → commit all-or-nothing → summary.
  Columns the matcher misses are picked by hand (`PUT /imports/:id/mapping`).
- Re-import updates by natural key; blank cells keep stored values; unchanged rows show as
  "No change".
- Files over 1,000 rows are read and committed on the `p1.imports` queue, page polls progress.
- Uploads go to the compose `storage` service when `S3_ENDPOINT`/`S3_BUCKET` are set, else to
  a temp folder (dev/test only; CI has no storage).
- Screens: `/imports`, `/imports/new?kind=`, `/imports/[id]`; nav "Import from Excel"; each
  setup wizard step links to its import ("Have this in Excel already?").
- Checks: shared unit tests; API e2e `apps/api/test/masterdata-imports.e2e.test.ts` (20 tests,
  incl. hod per-row permissions, rollback, the chain programmes → courses → sections →
  students → teaching, and the 1,001-row background path with Redis); existing master-data
  e2e tests; Playwright `apps/web/e2e/p1/imports.spec.ts` and `setup-wizard.spec.ts` pass in
  Edge; `/imports`, upload, preview and inline fix checked at 400px light and dark (no sideways
  scroll).
